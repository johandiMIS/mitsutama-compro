# Products Content

Page-ready content for every item in the **Products** mega-menu, one file per item,
foldered by brand.

Each file carries YAML frontmatter (`title`, `brand`, `category`, `nav_label`, `slug`,
`source`, `status`) and ends with a **Source** section naming exactly where the content
came from. Every file is `status: draft` — none has been reviewed by Mitsutama.

Sources are the three documents and the link list in `contents/source/`:

| Source | Covers |
| --- | --- |
| `Konten Website PRODUCT.docx` | The content brief — maps every Products item to a vendor URL. Authoritative for item naming |
| `Chroma Power Electronic Test.pdf` | Chroma → Power Electronic Test and Equipment |
| `Audio-Precision-AppNote-Automotive-Audio-Amplifier-Testing.pdf` | Audio Precision → Automotive Entertainment Test and Equipment |
| `links.md` | Two IMC URLs, both already in the docx |
