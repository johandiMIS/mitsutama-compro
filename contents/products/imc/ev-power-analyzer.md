# EV Power Analyzer

## Overview

imc provides measurement and test solutions for electric vehicle development across the
entire EV powertrain. The platform lets engineers measure electric motors, batteries, fuel
cells, connectors and charging stations using high-voltage isolation technology and mobile
data acquisition — recording transitions between idle and operating states without
interruption, in one single continuous measurement.

## Components Tested

- Electric motors — drive and auxiliary
- Battery systems — cells, HV batteries, DC link
- Power electronics and inverters
- Charging infrastructure — connectors and charging stations
- Vehicle electrical systems and ECU controls

## Measured Quantities

| Quantity | Range and detail |
| --- | --- |
| Temperature | Thermocouples and RTD sensors at potentials up to 1400 V |
| Voltage | Small signals up to 1500 V DC, 1000 V rms AC |
| Current | 50 nA to 50 A, with power analysis |
| Power | 1-, 2- and 3-phase; effective, apparent and reactive power |
| Mechanical power / torque | Via telemetry on rotating shafts |
| Chassis | Wheel forces and brake temperatures |
| Acoustic | Noise, vibration and harshness (NVH) |

## Key Equipment

### Data Acquisition

| System | Description |
| --- | --- |
| CANSAS series | CAN-based modules with HV isolation |
| CRONOSflex | Modular platform, 100 kHz sampling |
| HISO-T | Thermocouple module for high-potential points |
| HISO-HV | High-voltage module |
| CANSAS-IHR | Wide-range current module |

### Sensors

| Sensor | Description |
| --- | --- |
| WFT-Cx | Six-component wheel force transducer |
| WTT-Dx | Torque measurement wheel |
| Dx-Speed, Dx-BrakeTemp | Telemetric wheel sensors |
| Current transducers, Rogowski coils | Current measurement |

### Software

imc STUDIO (real-time measurement and control), FAMOS (test data analysis), imc WAVE
(live NVH analysis) and imc Online FAMOS (real-time signal processing).

## Capabilities

- High-voltage isolation to 1000 V CAT II
- Auto-ranging current measurement, 50 nA–50 A continuous
- Online power calculation during acquisition
- Telemetric mechanical power measurement on rotating shafts
- EMC and ESD robustness for high-potential measuring points
- Integrated test stand automation for motor, inverter and battery systems

## Standards Referenced

- EN 61010 — device safety
- LV124, LV123, LV148 — automotive electrical system certification
- CAT II measurement categories

## Why It Matters

Continuous, uninterrupted measurement across idle and operating states enables
comprehensive efficiency optimisation and component validation for next-generation EVs.
