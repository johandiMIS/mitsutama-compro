# Inverter Test and Equipment

## Overview

A photovoltaic inverter converts the direct current (DC) output of a solar cell or array
into alternating current (AC). Chroma provides the test instrumentation to validate that
conversion across the full development and production cycle — solar array simulation,
grid simulation, MPPT performance, anti-islanding protection and electrical safety.

## Inverter Types Covered

| Type | Description |
| --- | --- |
| Grid-tie (GTI) | Connected to utility mains; synchronises generated power to the grid |
| Off-grid | Independent systems storing power in batteries rather than feeding the grid |
| Hybrid | Combination systems with battery backup capability |

## Test Applications

### Maximum Power Point Tracking (MPPT)

Validation of MPPT circuit and algorithm performance, operating voltage limits and
efficiency, dynamic curve performance to **EN 50530**, **Sandia** and **CGC/GF004**, and
temperature-dependent performance simulation.

### Anti-Islanding Protection

Verifies the inverter's ability to disconnect safely when grid problems are detected.

### Solar Array Simulation

Tests inverter behaviour under steady, repetitive control conditions that simulate
real-world irradiance, temperature and weather variation — removing the dependency on
actual sunlight conditions.

### Grid Simulation

Tests compliance with **IEEE 1547**, **IEC 61000-3-15** and **IEC 62116** for safe
grid-connected operation.

### Electrical Safety

AC/DC hipot, leakage current, insulation resistance and ground continuity testing.
